# Accelerated Patterns documentation contract

## Goal

Create one continuous, result-first Patterns reference for Charts, Tables,
Forms, Navigation, and Transactions. Mount only the four approved lightweight
representatives named by the handoff; keep Transactions visibly Exploring and
Paused without a canonical specimen.

## Current state

The Patterns page exposes Charts as a status row and treats Tables, Forms,
Navigation, and Transactions as legacy aliases. The full review/detail routes
remain mixed-depth compatibility surfaces.

## Non-goals

Do not change pattern authority, frozen family internals, product behavior,
fixtures, shared defaults, catalogs, accepted decisions, production adoption,
or existing detail/hash/query contracts. Do not publish or alter Git history.

## Acceptance evidence

Pin all five anchors, four real representative specimens, the honest paused
Transactions boundary, exact Workbench and Records links, direct alias reloads,
light/dark responsive behavior, keyboard focus, overflow containment, artifact
isolation, and byte identity for frozen family internals.

## Test seams

Use the Patterns aggregate DOM as the highest stable behavior seam, the
standalone browser entry for rendered/runtime proof, existing family smoke tests
for compatibility, and the production build/import graph for isolation proof.

## Slices

1. Record live scoped identities and freeze excluded family hashes.
2. Add RED aggregate and browser coverage.
3. Implement the documentation-only projection and five wrappers.
4. Capture the first complete render, review, and apply one bounded repair pass.
5. Run the final affected-surface matrix and write the durable receipt.

## Unresolved decisions

Stop only the affected subsection if it requires new pattern authority,
invented surrounding UI, financial/data/palette changes, a universal Table API,
navigation behavior, or resumed Transaction design. The remaining subsections
continue independently.
