## What this means for the next work

Do not start another matched experiment by default. One run per package and a
no-browser performer boundary cannot evaluate the normal render-and-correct loop.
The documentation fix and exposed APIs have direct evidence of usefulness; the
remaining weaknesses require choosing and inspecting a suitable composition.
The new hints have static/source support, **not new measured agent-performance
proof**. Revisit an isolated comparison only if the same problem persists or a
specific causal question would change the implementation decision.

For the already prepared table work: directly inspect the production surfaces
and evidence behind the research, establish cell/value meaning, and render the
two bounded anchors before expanding the family. Use Exposure/Collateral as the
leading stacked-mobile predecessor where appropriate, not as a universal table.
That is a lab application loop, not permission to migrate production or clear S5.
