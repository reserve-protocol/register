# Register design system

The sidebar runs from the smallest pieces to the largest, then to work that is not accepted yet.

- **Foundations**: the rules everything follows: colour, typography, spacing, radius, layout, elevation, motion, iconography and accessibility. **Success surface** is the background used only on transaction success screens.
- **Components**: single building blocks such as buttons, fields, tabs, dialogs and status labels. Start here when building UI.
- **Patterns**: larger pieces taken from real screens: navigation, market tables, charts and transaction flows. Each page's Docs explains its states and data.
  - **Transactions (In progress)** holds complete multi-step flows (issuance, staking, vote lock, zapper). They are the most complex examples and are still exploratory.
- **Dashboard (unreviewed)**: proposed pieces for the eUSD activity landing page. Start at its Overview.
- **Explorations**: proposals, screen pilots and older studies. Nothing here is part of the accepted system.

Anything marked **(In progress)** or **(unreviewed)**, and everything under **Explorations**, is not part of the accepted contract.

Use **Controls** to change props and transaction stages. Switch theme in the toolbar. Responsive examples provide width or layout controls above their previews; full-screen examples respond to the browser width. Open **Code** for the example source.

Examples use mock data. Transactions do not execute.
