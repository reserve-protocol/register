# Register design system

Start with **Components** to find an implementation, **Patterns** to review a product composition, or **Foundations** to inspect the visual rules. **Explorations** preserves proposals whose production adoption is still open.

Use **Controls** to change supported props, the toolbar to switch theme and viewport, and **Code** to inspect the example. Component Docs include the canonical import and usage boundaries. The **Accessibility** panel reports automated findings; keyboard, content and visual review still matter.

For transaction stages, use the **state** control; form inputs remain editable.

Examples use local fixtures. Wallet connections, quotes, approvals and transaction results are design states. They do not execute real transactions. English reference copy stays outside production translation catalogs.
