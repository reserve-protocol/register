# Register design system

- **Foundations** — colors, typography, spacing and motion.
- **Components** — reusable UI and its states.
- **Patterns** — navigation, tables, charts and transactions.
- **Explorations** — alternative layouts and early design studies.

Use **Controls** to change props and transaction stages. Switch theme and screen size in the toolbar; open **Code** for the example source.

Examples use mock data. Transactions do not execute.
